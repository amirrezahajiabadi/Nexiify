# 🎨 Nexify — نقشه‌ی راه بهبود UI/UX (UIUX Roadmap)

> مبنای این نقشه‌ی راه: **ممیزی کامل UI/UX** با اسکیل `ui-ux-pro-max` (۱۱ اوت ۲۰۲۶) — کنتراست محاسبه‌شده، رندر زنده در مرورگر، چک‌لیست پیش از تحویل اسکیل، و الگوی «Enterprise Gateway» پیشنهادی اسکیل برای آژانس AI.

### فاز U3 — دسترس‌پذیری مودال و کیبورد (اولویت ۲) ✅ (۱۱ اوت ۲۰۲۶)

- [x] **Focus trap**: هندلر `keydown` سراسری (فقط وقتی مودال باز است) — Tab وقتی فوکوس بیرون است به داخل می‌آورد؛ Shift+Tab از اولی → آخری (لینک GitHub)؛ Tab از آخری → اولی (دکمه‌ی بستن).

- [x] **بازگشت فوکوس**: بعد از بستن (Esc / دکمه‌ی بستن / کلیک بیرون) فوکوس به دکمه‌ی مبدأ برمی‌گردد (`lastTrigger`).
- [x] چک: اسکرول پس‌زمینه قفل است (از قبل `lockScroll` ✓) + Esc فقط وقتی مودال باز است عمل می‌کند.
