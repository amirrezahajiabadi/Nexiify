## ۲) فازها

### فاز U1 — دسترس‌پذیری پایه: کنتراست + فرم‌ها (اولویت ۱) ✅ (۱۱ اوت ۲۰۲۶)
- [x] **رفع کنتراست**: `--text-muted` تیره `#555` → `#9ca3af` (۷.۸:۱ ✓)؛ روشن `#888` → `#6b7280` (۴.۸:۱ ✓). `--text-secondary` روشن `#555` → `#4b5563` (۷.۱:۱ ✓). تیره `#888` → `#a3a3a3` (۷.۸:۱ ✓). *(در style.css — هر دو تم)*
- [x] اسکن مجدد همه‌ی جفت‌رنگ‌ها — همه ≥ ۴.۵ برای متن معمولی (تأیید زنده در مرورگر: تم تیره `#9ca3af`، تم روشن `#6b7280`).
- [x] استثنا فقط برای متن‌های تزئینی/بزرگ — مورد تزئینی با rgba ثابت پیدا نشد (۴۳ استفاده‌ی `text-muted` همگی متن خواندنی).
- [x] فرم تماس: `id` روی ۷ input + `for` روی label ها (تست رگرسیون `test_form_labels_connected_to_inputs`)؛ خبرنامه: `id` + `aria-label`. *(سلکت مخفی `hiddenSelect` → `id_request_type` و contact.js همگام شد)*
- [x] `type="button"` روی `theme-toggle`، `mobile-toggle`، `back-to-top`، `mobile-menu-close`.
- **فایل‌ها**: `static/css/style.css`، `static/css/contact.css`، `static/css/auth.css`، `static/css/panel.css`، `templates/contact.html`، `templates/blog/blog_list.html`
- **تعریف تمام**: محاسبه‌ی کنتراست هر جفت ≥۴.۵ + تست کلاینت فرم‌ها + `pytest` سبز + تأیید بصری هر دو تم.

### فاز U2 — یکسان‌سازی آیکون‌ها: همه SVG شیشه‌ای (اولویت ۱) ✅ (۱۱ اوت ۲۰۲۶)
- [x] **منبع واحد آیکون**: `apps/core/icons.py` (۲۶+ آیکون stroke-based با کلید ایموجی → SVG) + فیلتر `{% load core_extras %}` و `{{ "X"|icon_svg }}` (mark_safe).
- [x] جایگزینی در همه‌ی صفحات: کارت‌های اطلاعات تماس (`✉⌘◉`)، شبکه‌های اجتماعی (`⌥✉in➤`)، روش تماس تلفنی (`📞`)، گزینه‌های سلکت (`🧠🌐📱🤖⚙️📚💡` از views.py با `data-svg`)، تیک موفقیت/روش تماس، ارزش‌های درباره (`🎯🤝📈`)، بصری درباره (`👨💻`)، آیکون‌های خدمات (`🌐🤖🧠⚙️📚` + CTA `💬`)، placeholder بلاگ/پروژه (آیکون دیتابیس با `|icon_svg`)، متای بلاگ (`📅⏱`)، favicon (⚡ → مسیر بُلت SVG)، کنترل‌های UI (`☀️🌙☰✕↑`)، پنل ادمین (برند + ۷ آیکون منو + نمودار + دکمه‌ی ویرایش).
- [x] **مودال پروژه**: آیکون SVG کارت clone می‌شود (بدون ایموجی و بدون innerHTML).
- [x] CSS: `.icon-svg { width:1em }` سراسری (هم‌اندازه با فونت زمینه) + ۲ override دقیق (method-check ۱۲px، brand پنل ۱۸px).
- **فایل‌ها**: `apps/core/icons.py` + `apps/core/templatetags/core_extras.py`، ۱۲ تمپلیت، `static/js/contact.js` + `projects.js`، ۵ فایل CSS
- **تعریف تمام**: ✅ اسکن ایموجی خارج از فیلتر = فقط ۲ مورد متنی (👋✨ در متن خوش‌آمد — عمدی) + تأیید DOM هر ۸ صفحه (صفر ایموجی در اسلات آیکون، همه SVG با اندازه‌ی درست) + ۹۴ تست سبز.

### فاز U3 — دسترس‌پذیری مودال و کیبورد (اولویت ۲)
- [ ] مودال پروژه: `role="dialog"` + `aria-modal="true"` + `aria-labelledby` → عنوان.
- [ ] **Focus trap**: Tab داخل مودال بماند؛ فوکوس اولیه روی دکمه‌ی بستن؛ بعد از بستن، فوکوس به دکمه‌ی مبدا برگردد.
- [ ] چک: اسکرول پس‌زمینه قفل باشد (از قبل `lockScroll` ✓).
- **فایل‌ها**: `static/js/projects.js`، `static/css/projects.css`
- **تعریف تمام**: تست دستی Tab-cycle در مرورگر + Esc + کلیک بیرون.

## ۵) قوانین برای هر AI آینده
1. **هرگز کنتراست زیر AA (۴.۵:۱) برای متن معمولی اضافه نکن** — قانون طلایی جدید.
2. **ایموجی به‌عنوان آیکون ممنوع** — همیشه SVG (Heroicons/Lucide یا SVG سفارشی شیشه‌ای پروژه).
3. **فوکوس کیبورد همیشه نمایان** — `:focus-visible` در همه‌ی المان‌های تعاملی.
4. **reduced-motion محترم شمرده شود** — هر انیمیشن جدید + بلاک `@media (prefers-reduced-motion)`.
5. هر اسکیل UI/UX (مثل `ui-ux-pro-max`) قبل از تصمیم‌های طراحی مشورت شود: `python ../.agents/skills/ui-ux-pro-max/scripts/search.py "<نوع محصول>" --design-system -p "Nexify"`.
