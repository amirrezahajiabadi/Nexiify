# 📦 بایگانی نسخه‌ی استاتیک (قبل از Django)

این پوشه شامل صفحات HTML و فایل‌های مربوطه از **نسخه‌ی استاتیک** پروژه است (فاز ۰ تا ۳).

با اجرای **فاز ۴**، این فایل‌ها به قالب‌های جنگو در `templates/` تبدیل شدند و این نسخه فقط برای **مرجع و مقایسه** نگهداری می‌شود:

- `index.html` `about.html` `services.html` `projects.html` `blog.html` `contact.html` → `templates/*.html`
- `admin.html` → با **Django Admin** (`/admin/`) جایگزین شد
- `admin.css` `admin.js` → مربوط به پنل نمایشی قبلی

> برای مشاهده‌ی این نسخه: یک سرور استاتیک روی ریشه‌ی Nexify اجرا کنید (فایل‌های `css/ js/ fonts/` به `static/` منتقل شده‌اند و در این نسخه‌ی بایگانی باز نمی‌شوند).
